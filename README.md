# Techcare – Customer Service Management System

## Project Overview
Techcare is a C-based application designed to manage customer service operations efficiently using various data structures.

It helps organize customer records, handle support tickets, manage device exchanges, and maintain resolved ticket history and customer feedback.

## Features
- Customer Registration and Management
- Priority-Based Ticket Handling
- Device Exchange Management
- Resolved Ticket History
- Customer Feedback System

## Data Structures Used
- Binary Search Tree
- Stack
- Linked List
- Priority Queue
- Deque

## Technologies Used
- C Programming
- Data Structures

## Project Objective
To apply fundamental data structures in a practical customer service management application.

## How to Run
1. Install a C compiler such as GCC.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Compile the source file:

```bash
gcc main.c -o techcare
```

5. Run the program:

```bash
./techcare
```

On Windows, use:

```bash
techcare.exe
```
